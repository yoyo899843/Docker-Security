What is Docker

Docker 是什麼？

Docker 把應用程式和它需要的一切（執行環境、套件、設定檔）打包成一個標準化的「容器」。就像海運貨櫃：不管裡面裝什麼，船、碼頭、卡車都用同一套方式搬運。容器在你的筆電、同學的電腦、雲端主機上，跑起來都一樣。

從此不用再說「可是在我的電腦上明明可以跑」。

傳統虛擬機 (VM)Docker 容器
包含什麼完整的作業系統只有應用程式與相依套件，共用主機核心
啟動時間數十秒到數分鐘通常一秒內
大小好幾 GB幾 MB 到幾百 MB（這個 nginx 映像檔約 50 MB）
隔離程度較強，各自有核心行程層級隔離
Core concepts

四個核心觀念

Dockerfile 建置說明書

一份文字檔，一行一個步驟，描述映像檔要怎麼做出來：從哪個基底開始、複製哪些檔案、執行什麼指令。

Image 映像檔

依照 Dockerfile 建置出來的唯讀模板。可以上傳到 Docker Hub 分享，例如這次用到的 nginx。

Container 容器

映像檔執行起來的實體。同一個映像檔可以同時跑好幾個容器，彼此互不干擾。

Compose 多容器編排

用一個 YAML 檔描述要跑哪些服務、開哪些 port、掛哪些資料夾，一行指令全部啟動。

How this page got here

這個網頁是怎麼跑起來的

  1. 寫 Dockerfile

    以官方的 nginx 映像檔為基底，把 index.html 複製進 Nginx 的網站目錄。

  2. 寫 docker-compose.yml

    指定用哪個 Dockerfile 建置，並把主機的 8080 port 對應到容器的 80 port。

  3. 建置並啟動

    Compose 會先建置映像檔，再用它啟動容器。

    $ docker compose up -d --build
# 打開 http://localhost:8080 就看到這一頁了
Cheat sheet

常用指令

指令用途
docker compose up -d --build建置映像檔並在背景啟動所有服務
docker compose ps查看目前有哪些容器在跑
docker compose logs -f即時查看容器的 log（可以看到你剛剛的瀏覽紀錄）
docker compose down停止並移除容器
docker images列出本機的映像檔
docker exec -it <容器> sh進入容器裡面看看
小挑戰：修改這個 index.html 的標題，重新執行 docker compose up -d --build，重新整理網頁看看有沒有變。
